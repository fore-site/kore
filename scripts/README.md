# Scripts

Foundry scripts for interacting with the Telegraph Diamond contract on Base Sepolia.

## Setup

```bash
# Install Foundry
curl -L https://foundry.paradigm.xyz | bash
foundryup

# Configure environment
cp .env.example .env
# Fill in EVM_HTTP_URL and PRIVATE_KEY
```
